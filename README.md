# 🎬 CineVault

**Платформа для каталогизации, анализа и хранения видеоколлекций.**

Единое приложение для управления личной видеотекой: фильмы, сериалы, документальное кино — из стримингов, локальных файлов и с физических носителей.

---

## 🎯 Проблема

Киноманы, кинокритики и коллекционеры теряют контроль над своими видеоколлекциями:

- **20–25%** контента забывается
- **30%** времени уходит на поиск нужного фильма
- Данные разбросаны: стриминги, локальные файлы, физические носители

## 💡 Решение

Единый каталог с быстрым добавлением, мгновенным поиском, аналитикой, рекомендациями и напоминаниями.

| Метрика            | Было       | Стало            |
| ------------------ | ---------- | ---------------- |
| Добавление позиции | 2–4 минуты | **20–30 секунд** |
| Поиск фильма       | 5–10 минут | **< 10 секунд**  |
| Потеря контента    | 20–25%     | **0%**           |

## ✨ Возможности

### Каталог

- 📥 Импорт из TMDB — **1600+ фильмов и сериалов** с постерами, актёрами, режиссёрами
- 🔍 Мгновенный поиск с подсветкой совпадений
- 📑 6 вкладок: Все / Просмотренные / Смотрю / В планах / Любимые / С носителей
- 🎯 Фильтры по источнику (стриминг / локально / носитель) и жанрам

### Персонализация

- 👤 Профиль с аватаром, ФИО, работой, био, соцсетями
- ⭐ Оценки, избранное, теги
- 📊 Дашборд с аналитикой и напоминаниями о недосмотренном

### Умные рекомендации

- 🤖 Гибридный алгоритм: content-based + collaborative filtering
- 🎯 Персональные подборки с объяснением

### РФ-сервисы

- 🔗 Deep links на Кинопоиск, Иви, Okko, Premier, Wink, More.tv, START

### Админ-панель

- 👑 Управление пользователями, ролями, статусами email
- 🎬 Просмотр и модерация каталога фильмов

## 🚀 Быстрый старт

### Требования

- **Node.js 18+**
- **Gmail App Password** — [инструкция](https://myaccount.google.com/apppasswords)
- **TMDB API Key** — [регистрация](https://www.themoviedb.org/signup)

### Установка

```bash
git clone <URL-репозитория>
cd cinevault

# Backend
cd backend
npm install
cp .env.example .env
# Открой .env и заполни значения

# Frontend
cd ../frontend
npm install
```

### Импорт данных

```bash
cd backend

# Базовый seed (15 демо-фильмов + 5 тестовых юзеров)
npm run seed
npm run create-test-users

# Импорт из TMDB (~8 минут) — нужен VPN в РФ
npm run import-tmdb

# Импорт РФ-контента (~6 минут)
npm run import-ru

# Дозаполнение постеров и фото актёров
npm run update-posters
npm run fix-people

# Назначить админа
npm run migrate-admin
```

### Запуск

**Терминал 1 — backend:**

```bash
cd backend && npm run dev
```

**Терминал 2 — frontend:**

```bash
cd frontend && npm run dev
```

Открой http://localhost:5173
